# Student Portfolio Website Project Note

My project is a Student Portfolio website developed using HTML and CSS. The purpose of this website is to introduce myself, display my skills, present my projects, share my educational background, and provide my contact information. The website is designed for lecturers, students, and other people who want to learn about me and my work.

I used CSS Grid to arrange the skills and project cards into columns. Grid makes it easier to organize the content and maintain a neat layout. I also used Flexbox to arrange the navigation bar and align items on the webpage. Flexbox helps position items neatly and distribute space between them.

To make the website responsive, I used media queries in CSS. These allow the layout to change when the screen becomes smaller. For example, the project cards change from multiple columns to a single column on smaller screens. This makes the website easier to read and use on mobile phones.

One challenge I encountered was arranging the content so that it looked good on both large and small screens. I addressed this by using CSS Grid, Flexbox, and media queries to adjust the layout. Through this project, I gained practical experience in building and styling a responsive website using HTML and CSS.
